# 实验003计划：恢复退化能力

## 背景

实验002将40题准确率从42.5%提高到57.5%，但预算约束、信息不足和无合适商品三个类别退化。实验003的目标是在保留否定属性、数值筛选和完整摘要提升的同时，恢复这些退化能力。

## 控制变量

继续使用Qwen2.5-0.5B-Instruct、3 epochs、学习率2e-4、有效批大小16、LoRA r=16/alpha=32和相同推理参数。唯一主要变量仍是训练数据。

## v3数据

- 保留v2的9种任务结构；
- 新增显式价格大小比较，答案直接表达“大于预算”和“小于或等于预算”；
- 新增两款商品全部超预算；
- 新增两款商品全部缺少必选属性；
- 新增只缺一个硬性属性的信息不足场景；
- 默认生成2600条训练、325条验证，13种结构各200/25条；
- v3另存为`sft_train_v3.jsonl`和`sft_validation_v3.jsonl`，不覆盖v2数据。

## 成功标准

1. 40题总体准确率高于实验002的57.5%；
2. 预算约束、信息不足和无合适商品均高于实验002；
3. 否定属性、数值筛选和完整摘要不出现明显退化；
4. 若总体提升但关键类别再次失衡，则停止机械增加合成数据，转向更强基座模型或结构化约束方法。
