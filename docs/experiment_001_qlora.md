# 实验001：Qwen2.5-0.5B-Instruct QLoRA/SFT

## 实验目的

验证“数据构造—QLoRA训练—Adapter部署—固定业务评测”的完整闭环，并以同一评测集比较基座与SFT模型。

## 环境与参数

| 项目 | 配置 |
|---|---|
| GPU | NVIDIA RTX 3090 24GB |
| PyTorch / CUDA | 2.5.1 / 12.4 |
| 量化 | 4-bit NF4，double quant，BF16计算 |
| 数据 | 1200条训练、150条验证 |
| Epochs | 3 |
| Batch | 2 × 梯度累积8 = 有效批大小16 |
| Learning rate | 2e-4，cosine scheduler |
| LoRA | r=16，alpha=32，dropout=0.05 |
| 可训练参数 | 8,798,208（总参数的1.7497%） |
| 训练时间 | 673.13秒（约11分13秒） |

## 结果

| 模型 | 严格通过 | 严格准确率 | 平均延迟 |
|---|---:|---:|---:|
| 基座模型 | 2/8 | 25% | 约8.08秒（本地CPU） |
| SFT + LoRA | 4/8 | 50% | 约1.57秒（RTX 3090） |

最终验证loss为0.000131，验证token准确率为100%。该结果主要说明模型已充分拟合结构相似的合成验证数据，不能等同于真实电商泛化能力。

## 失败案例

1. 预算约束：将299元商品错误判断为符合250元预算。
2. 事实摘要：正确抽取容量、材质和保温时间，但漏掉89元价格。
3. 否定属性：把“高度不可调节”错误改写成“可以高度调节”。
4. 数值字段：混淆价格与容量，未选择满足容量要求且价格最低的商品。

## 结论与下一轮设计

首轮SFT将固定评测准确率提高25个百分点，证明训练管线有效；错误集中在否定表达、数值字段绑定和多约束联合判断。下一轮保持模型和超参数不变，只扩充并改写训练数据，从而把效果变化归因于数据质量，而不是同时修改多个变量。
