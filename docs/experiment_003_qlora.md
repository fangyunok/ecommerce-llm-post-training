# 实验003：拒答与预算能力恢复实验

实验003保持模型与超参数不变，使用13种结构、2600/325条v3数据，重点增加预算显式比较、全部超预算、全部缺少属性和单项信息缺失。

## 训练

- RTX 3090 24GB，3 epochs，489 steps；
- 训练时间1629.89秒（约27分10秒）；
- 最佳验证loss约0.001251；
- Adapter保存于`outputs/sft_adapter_v3`，权重不提交GitHub。

## 40题结果

| 类别 | 实验002 | 实验003 |
|---|---:|---:|
| 总体 | 23/40（57.5%） | 21/40（52.5%） |
| 预算约束 | 2/6（33.3%） | 3/6（50.0%） |
| 信息不足 | 0/3（0%） | 1/3（33.3%） |
| 无合适商品 | 0/3（0%） | 1/3（33.3%） |
| 否定属性 | 6/8（75.0%） | 4/8（50.0%） |
| 数值筛选 | 6/11（54.6%） | 4/11（36.4%） |
| 完整摘要 | 7/7（100%） | 6/7（85.7%） |
| 必选属性 | 2/2（100%） | 2/2（100%） |

## 结论

实验003 恢复了拒答与预算能力（信息不足、无合适商品各 `0/3 → 1/3`，预算约束 `2/6 → 3/6`），同时总体为 `21/40`（52.5%），实验002 的 Adapter 仍是当前总体最佳。

本次实验给出了明确的判断：继续机械增加模板化合成数据收益有限。由此把优化方向从「扩大数据」转向「提升基座能力 + 结构化规则与模型协同」，并引入少量高质量人工数据——这也是后续实验004、005 的起点；偏好对齐（DPO）留待基础数字比较与事实绑定被确定性方案覆盖后再引入。
