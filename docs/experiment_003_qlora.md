# 实验003：退化能力恢复实验

实验003保持模型与超参数不变，使用13种结构、2600/325条v3数据，重点增加预算显式比较、全部超预算、全部缺少属性和单项信息缺失。

## 训练

- RTX 3090 24GB，3 epochs，489 steps；
- 训练时间1629.89秒（约27分10秒）；
- 最佳验证loss约0.001251；
- Adapter保存于`outputs/sft_adapter_v3`，权重不提交GitHub。

## 结论

实验003恢复了部分拒答和预算能力，但总体准确率下降5个百分点，并导致实验002已经改善的类别回落，未达到预设成功标准。当前总体最佳模型仍为实验002 Adapter。

因此停止继续机械增加模板化合成数据。下一阶段应优先考虑更强的基座模型、结构化规则与模型协同，或引入少量高质量人工数据；DPO不能替代基础数字比较和事实绑定能力。
