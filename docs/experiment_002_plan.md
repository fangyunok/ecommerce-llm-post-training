# 实验002计划：数据质量对照实验

## 假设

实验001的验证loss接近0，但固定业务评测仅为4/8。原因不是模型没有拟合训练数据，而是旧数据只有5种高度固定的结构，未充分覆盖预算边界、否定表达和多字段数值绑定。

## 唯一实验变量

只改变训练数据，保持基座模型、随机种子、训练轮数、学习率、有效批大小和LoRA参数与实验001一致。

## 数据变化

- 从1200/150条扩大到1800/225条；
- 从5类扩展到9类，每类训练200条、验证25条；
- 加入等于预算、高于预算1元和全部预算内等边界；
- 随机使用“不支持”“没有”“不具备”“不可”等否定形式；
- 加入三商品的容量、价格和性能联合筛选；
- 打乱摘要字段顺序，并要求完整覆盖指定字段。

## 评测设计

1. 先使用实验001 Adapter运行40题扩展评测，作为数据修改前基线。
2. 使用v2数据训练实验002 Adapter。
3. 在相同推理参数下再次运行同一40题。
4. 同时报告总体和分类准确率，并保留逐题输出。

## 成功标准

- 原8题不低于实验001的4/8；
- 40题总体准确率相对实验001 Adapter提升；
- 预算约束、否定属性和数值筛选三个目标类别均有改善；
- 若某类退化，必须记录失败案例，不只报告总体分数。
