# 实验008：真实1.5B模型抽取回退与统一接口验证

## 实验目的

验证规则解析器无法处理开放式中文描述时，系统能否调用真实的`Qwen2.5-1.5B-Instruct + 实验004 LoRA Adapter`抽取结构化约束，再由确定性规则完成筛选与排序。

## 环境与方法

- GPU：AutoDL RTX 3090 24GB
- 推理精度：BF16
- 模型：`Qwen/Qwen2.5-1.5B-Instruct`
- Adapter：`outputs/sft_adapter_1_5b_v2`
- 解码：`do_sample=false`
- 困难集：5条开放式商品比较文本，且均确认无法由现有确定性解析器直接处理

链路为：规则解析失败 → 1.5B模型输出JSON → 单位归一化 → 基于原文明确短语校正约束方向 → Pydantic Schema校验 → 确定性推荐。任何JSON或Schema错误都返回失败，不让未经校验的模型结果进入决策引擎。

## 结果

首轮通过`3/5`。失败原因分别是模型输出`"64MP"`而不是数字，以及将“不能重于1.5kg”错误映射成`gt`。加入通用单位归一化和原文约束方向校验后，固定困难集通过`5/5`。

统一接口另外验证了三条实际路由：确定性解析、LLM抽取后规则决策、普通语言模型回答，结果为`3/3`。原始结果保存在：

- `outputs/evaluation/llm_fallback_v1.jsonl`
- `outputs/evaluation/llm_fallback_v1.summary.json`
- `outputs/evaluation/unified_api_v1.json`

## 结论与边界

该实验说明小规模真实模型可以补充规则解析覆盖面，但不能直接承担数值决策。可靠性来自“模型负责理解、代码负责计算、Schema负责拦截”的组合，而不是模型本身达到100%准确。

5条样本只能作为链路验收，不能代表线上泛化准确率。后续应扩展人工改写集，增加同值多约束、隐含单位、否定嵌套和无关信息，并分别统计抽取字段准确率、约束方向准确率与最终决策准确率。
