# 实验002：多样化数据质量对照实验

## 实验目的

验证实验001的主要瓶颈是否来自训练数据结构单一。实验002保持模型与训练超参数不变，只将SFT数据从5类1200/150条扩展为9类1800/225条。

## 环境与参数

| 项目 | 配置 |
|---|---|
| GPU | NVIDIA RTX 3090 24GB |
| PyTorch / CUDA | 2.5.1 / 12.4 |
| Epochs / steps | 3 / 339 |
| 有效批大小 | 2 × 梯度累积8 = 16 |
| Learning rate | 2e-4，cosine scheduler |
| LoRA | r=16，alpha=32，dropout=0.05 |
| 可训练参数 | 8,798,208（1.7497%） |
| 训练时间 | 1059.95秒（约17分40秒） |
| 最终验证loss | 0.001231 |

## 40题扩展评测

| 类别 | 实验001 | 实验002 | 变化 |
|---|---:|---:|---:|
| 总体 | 17/40（42.5%） | 23/40（57.5%） | +15.0个百分点 |
| 否定属性 | 2/8（25.0%） | 6/8（75.0%） | +50.0个百分点 |
| 数值筛选 | 1/11（9.1%） | 6/11（54.6%） | +45.5个百分点 |
| 完整摘要 | 5/7（71.4%） | 7/7（100%） | +28.6个百分点 |
| 必选属性 | 2/2（100%） | 2/2（100%） | 不变 |
| 预算约束 | 4/6（66.7%） | 2/6（33.3%） | -33.4个百分点 |
| 信息不足 | 2/3（66.7%） | 0/3（0%） | -66.7个百分点 |
| 无合适商品 | 1/3（33.3%） | 0/3（0%） | -33.3个百分点 |

原8题中实验002仍通过4题，与实验001持平，但通过和失败的具体题目发生变化。平均生成延迟从1.184秒变为1.242秒，差异很小。

## 结果解释

数据多样化明显改善了三个定向类别，支持“数据覆盖决定任务能力”的实验假设，也验证了分类指标比总体分数更能反映能力结构的变化。与此同时，每类训练数据被均衡为 200 条后，信息不足与无合适商品类别出现回落，0.5B 模型在相邻数字对应的商品名称上仍有混淆——这为实验003 的数据配比设计和后续的规则协同提供了明确的输入。

本实验定位为一个数据消融实验：用单变量对照量化数据覆盖对各类任务能力的影响，为后续实验确定训练数据方向。

## 下一步

1. 优先做数据配比设计（实验003），增加拒答、无匹配和预算约束样本权重，并减少模板化措辞。
2. 在训练前对生成答案增加规则校验，确保价格比较、否定属性和商品字段绑定正确。
3. 将 40 题扩展到至少 80 题，并人工复核自动判分规则。
4. 偏好对齐（DPO）留待基础事实抽取与数值比较由确定性规则或数据改造解决之后再引入。
